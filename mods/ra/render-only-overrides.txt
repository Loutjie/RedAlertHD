# Trait/field keys removed from both stock and this mod before the rules-parity check.
# Format: <ACTOR or ^ABSTRACT>:<TraitKey>[.<Field>]  # reason it cannot affect sync
# A ^ABSTRACT scope applies to every resolved actor (abstracts do not survive resolution).
World:TerrainRenderer  # stock tile renderer, replaced by the Remastered renderer; render-only, no effect on simulation
World:RemasterTerrainRenderer  # draws Remastered terrain art only; render-only, no effect on simulation
EditorWorld:TerrainRenderer  # ^BaseWorld is also inherited by EditorWorld; map editor only, never instantiated in a multiplayer match
EditorWorld:RemasterTerrainRenderer  # map editor terrain drawing only; render-only, no effect on simulation
World:ShroudRenderer.FogVariants  # selects which sprite sequence draws fog edges; drawing only, shroud/fog state is computed by the Shroud trait
EditorWorld:ShroudRenderer.FogVariants  # map editor only; drawing only
World:RemasterPlayerColorShift  # shifts the hue of RGBA sprites in the player palette to the player colour; palette/rendering only
EditorWorld:RemasterPlayerColorShift  # map editor palette only; rendering only
